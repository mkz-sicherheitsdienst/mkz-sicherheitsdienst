MKZ SICHERHEITSDIENST – WEBSITE-PAKET
====================================

Dateien
- index.html: Startseite mit Leistungen, Über uns, Kontaktformular
- styles.css: responsives Design (Dunkelblau & Weiß)
- script.js: mobiles Menü und Kontaktformular
- assets/mkz-logo.jpg: aus dem bereitgestellten Firmenprofil extrahiertes Logo
- impressum.html: Vorlage mit markierten Platzhaltern
- datenschutz.html: Datenschutz-Entwurf mit Hinweisen zur Anpassung

Vorschau
Öffnen Sie index.html in einem aktuellen Browser. Für eine lokale Vorschau kann ein einfacher Webserver verwendet werden.

WICHTIG ZUM KONTAKTFORMULAR
Das Formular verwendet mailto: und benötigt keinen eigenen Formularserver. Beim Absenden öffnet sich das E-Mail-Programm der Besucherin/des Besuchers mit einer vorbereiteten Nachricht an mkz.sicherheitsdienst@gmail.com. Die Nachricht wird nicht automatisch verschickt; die Person muss in ihrem E-Mail-Programm noch auf Senden klicken. Falls Sie ein Formular wünschen, das direkt auf der Website abgesendet wird, braucht es eine serverseitige Formularlösung bzw. einen Formularanbieter.

VOR DEM ONLINESTELLEN
1. Impressum vervollständigen (vollständiger Name, ladungsfähige Anschrift und weitere erforderliche Angaben).
2. Datenschutzhinweise an das tatsächliche Hosting und die verwendeten Dienste anpassen.
3. Kontaktformular, Telefonnummer und E-Mail-Adresse testen.
4. Prüfen, ob externe Google Fonts genutzt oder lokal eingebunden werden sollen.
5. Website auf einen Webhosting-Anbieter hochladen oder über einen Website-Host veröffentlichen.
